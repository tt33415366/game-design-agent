# 04: Extend an existing system and review the development handoff

**What to build:** The Game Designer adds a bounded system extension to an existing design and prepares a reviewed Development Handoff Draft grounded in authoritative rules and explicit evidence limits.

**Blocked by:** 02: Turn a Design Brief into actionable gameplay and system rules.

**Status:** complete

- [x] The existing-design extension scenario is actually exercised with retained input, output, and checks.
- [x] Contradictory or unimplementable critical rules block readiness.
