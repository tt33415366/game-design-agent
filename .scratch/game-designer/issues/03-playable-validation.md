# 03: Build a playable prototype and retain honest validation evidence

**What to build:** The Game Designer automatically builds a scoped local prototype after the agreed checkpoint, tests its rules, and reports what the evidence does and does not establish.

**Blocked by:** 02: Turn a Design Brief into actionable gameplay and system rules.

**Status:** ready-for-agent

- [ ] Design-prototype owns validation-plan and evidence templates.
- [ ] Scope and iteration limits govern execution; extra spending, publication, private uploads, and destructive changes remain approval-gated.
- [ ] At least one runnable prototype completes the ambiguous-idea acceptance scenario.
- [ ] Actual execution evidence includes rule checks and player-facing interaction checks, not only static inspection.
- [ ] Simulated approvals and unvalidated player-experience claims are explicitly labeled; prototype fidelity limits are recorded.
