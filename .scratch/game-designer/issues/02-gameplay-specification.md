# 02: Turn a Design Brief into actionable gameplay and system rules

**What to build:** The Game Designer develops core loops, compares established and innovative mechanics, and specifies systems precisely enough for developers to derive implementation tasks.

**Blocked by:** 01: Turn an ambiguous idea into a confirmed Design Brief.

**Status:** complete

- [x] Gameplay-design and system-design workflows have focused triggers and owned templates.
- [x] Rules include conditions, state transitions, edge cases, initial parameters, player feedback, and validation questions.
- [x] Each rule has one authoritative definition; references do not introduce contradictory copies.
- [x] Core gameplay, prototype scope, and a concrete iteration budget are submitted together for confirmation.
- [x] A constructed design scenario exercises both workflows and labels assumptions and unvalidated balance claims.
