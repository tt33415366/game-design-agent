# 01: Turn an ambiguous idea into a confirmed Design Brief

**What to build:** A repository-local Game Designer that selects dedicated skills, tracks project context, and turns a new idea or existing project into an actionable Design Brief without inventing user approvals.

**Blocked by:** None (can start immediately).

**Status:** complete

- [x] The agent entry point and design-intake workflow work in the current environment without global installation.
- [x] Intake covers target players, core experience, platform, team capabilities, time budget, and document language, asking only decision-changing questions.
- [x] A reusable Design Brief template records assumptions, authoritative documents, and confirmation state.
- [x] The three confirmation checkpoints and major-decision boundaries are explicit.
- [x] An ambiguous-input scenario is exercised and its actual output is retained.
