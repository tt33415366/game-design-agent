# 01: Turn an ambiguous idea into a confirmed Design Brief

**What to build:** A repository-local Game Designer that selects dedicated skills, tracks project context, and turns a new idea or existing project into an actionable Design Brief without inventing user approvals.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The agent entry point and design-intake workflow work in the current environment without global installation.
- [ ] Intake covers target players, core experience, platform, team capabilities, time budget, and document language, asking only decision-changing questions.
- [ ] A reusable Design Brief template records assumptions, authoritative documents, and confirmation state.
- [ ] The three confirmation checkpoints and major-decision boundaries are explicit.
- [ ] An ambiguous-input scenario is exercised and its actual output is retained.
