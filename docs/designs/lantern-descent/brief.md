## Design Assumptions

1. One descent is a meaningful unit; the game should not require grinding repeated runs for upgrades.
2. Pressure is environmental (darkness, current, narrowing space), not damage or a hard oxygen simulator unless the user explicitly wants that.
3. Each depth band contains a reveal, so turning back is a choice about incomplete knowledge, not merely a meter calculation.
