# Astra Orchestrator Compatibility Entry Point

This is the Codex-only compatibility entry point for the existing Codex profile.
Read [the shared orchestration policy](../../../agents/orchestration.md) before
delegating. It defines host-neutral ownership, context, independence, approval,
and evidence requirements.

For Codex sessions, use the existing role definitions in
`../../../.codex/agents/` and retain the configured Codex profile. This facade
does not expose that profile's settings or delegation policy to another host.
