# Game Design

Shared vocabulary for a Game Designer supporting independent developers and small teams.

## Language

**Game Designer**:
An agent acting as a game design collaborator, judged by the quality of its design reasoning rather than a claimed professional biography.
_Avoid_: Industry veteran with a real employment history

**Game Design Document**:
A specification of game rules, edge cases, initial parameters, and validation methods detailed enough for developers to derive implementation tasks.
_Avoid_: Creative pitch when referring to an implementation-ready design

**Game Prototype**:
A limited playable realization of a design intended to test its gameplay assumptions.
_Avoid_: Finished game

**Design Assumption**:
An explicitly labeled premise used to advance a design before that premise has been confirmed or tested.
_Avoid_: Confirmed requirement

**Innovative Alternative**:
A proposed departure from established mechanics with an identified experiential benefit, added risks, and a low-cost means of testing it.
_Avoid_: Novelty requirement

**Design Brief**:
The agreed framing of a game project, identifying its target players, core experience, platform, team capabilities, and time budget.
_Avoid_: Full game design document

**System Specification**:
The authoritative design description of a particular gameplay system, including its rules, edge cases, and initial parameters.
_Avoid_: Implementation architecture

**Prototype Validation Plan**:
A description of the design assumptions a prototype will test and how the resulting evidence will be evaluated.
_Avoid_: Proof of fun

**Development Handoff Draft**:
The design documentation submitted for confirmation before developers use it to derive implementation tasks.
_Avoid_: Guaranteed implementation plan

**Rule Verification**:
Evidence that specified game rules behave as defined within the tested cases; it does not establish the quality of the player experience.
_Avoid_: Proof of fun or balance

**Player Validation**:
Evidence from target players interacting with the game that informs judgments about its intended experience.
_Avoid_: Automated rule verification
