## Proposed Direction (Not Yet Approved Gameplay)

`Pocket Logic Lab`: a sequence of single-screen deduction puzzles. Each puzzle presents a small set of labeled switches and visible machine outputs. The player infers a hidden relationship from examples, then sets the switches to produce a requested output. Start with Boolean-style relationships and only introduce one new rule idea at a time.

Why this is a conservative fit: it makes discovery and cleverness the immediate reward, has no grind loop, avoids the excluded themes, and can be implemented with simple deterministic state and DOM/CSS feedback. This is a proposed direction, not an authoritative core loop or scope approval.

## Mechanic Proposal

Propose `Pocket Logic Lab`: a compact browser puzzle in which the player sees a simple panel of binary inputs and output lamps. Each short puzzle exposes examples generated by one relationship, then asks the player to configure inputs that produce a target output. The first playable slice uses only two inputs and a small relationship set, so each choice can be rendered and evaluated deterministically without procedural generation, economy systems, narrative branches, or repeated grind loops.

The player choice is a configuration, not a next-step selection. The stake is spending a limited number of in-puzzle attempts before the relationship is revealed; the observable outcome is an immediate output state plus a concise post-solve reveal. Exact attempts, legal inputs, relationships, transition ordering, and feedback are deferred to the system specification.
